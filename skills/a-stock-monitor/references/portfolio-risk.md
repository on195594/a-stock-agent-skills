## 组合风险前置检查

先取得用户的“可投资组合总资产”——股票市值 + 本策略可动用现金，不含房产、应急金：

```bash
$CACHE portfolio-risk --portfolio-value <总资产> --max-position-risk-pct 2
```

未提供总资产时只能用已取价股票市值作临时分母，可以监控但不得授权加仓。

### 风险预算

`单股风险贡献 = 股数 × max(现价 − 第二档止损价, 0) ÷ 可投资组合总资产`

- 默认单股上限2%、组合第二档止损风险合计上限8%；均为待回放验证的启发式默认值，
  用户有既定预算时以用户值为准；
- 任一单股或组合超限：禁止新增风险；
- 已跌破第二档的持仓单独标为“已破线”，不能因剩余风险为0显示正常。

### 集中度

- B银行+D公用事业/水电市值占股票总市值≥60%：置顶风格集中提醒；
- 第一大仓或单股权重≥25%：以①②③编号输出止损来源、L3逐条状态、估值退出距离；
  缺任一项不得建议持有或加仓；
- `portfolio-risk` 使用 `holdings.framework/framework_confident` 并按市值汇总。框架为
  `?` 时停止框架动作；需要变更时用 `holding-framework` 显式迁移并重算止损。

### 行为与宏观检查

- 总账浮盈首次由负转正时提示一次：不得因“回本”改变L3或估值纪律；
- 宏观变量必须写成
  `变量 → 传导路径 → 持仓 → 正/负/中性 → 操作影响`；
- 以“纯内需/无敞口”排除汇率、出口或海外资产路径前，必须核实最新财报中与该路径
  直接对应的收入、订单、外币资产负债或境外子公司数据。
