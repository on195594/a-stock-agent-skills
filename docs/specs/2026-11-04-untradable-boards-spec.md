# 账户板块权限：研究保留、建议排除（0.1.36）

授权：所有者 2026-11-04 在 Claude Code 会话中说明：“当前券商账号没有交易科创板股票的权限，暂时无法开通，我建议在研究中可以保留，在投资建议中需要排除”。

## 1 规则

- 个人风险政策文件增加可选字段 `untradable_boards`：账户无权限交易的板块列表，取值限 `STAR`（科创板，688）、`BSE`（北交所）。不可重复。缺省表示全部可交易。主板与创业板不在可限制范围内。
- 该字段只收窄建议、从不放开风险。因此，即使未提供匹配的 `--account-scope`、风险上限尚未生效，它也照样生效。快照中写入 `account.risk_policy.untradable_boards`，来源为 `policy_file`。
- 受限板块的公司照常研究：Research 报告、论点卡、立场与估值，以及 monitor-v1 的研究行，都不变。
- 投资建议一律排除受限板块：
  - 不出 `research_opportunity` 机会提示；
  - 不作 `opportunity_cost` 换仓候选，次优的可交易候选照常比较；
  - `position-size` 拒绝定仓；
  - 研究报告的动作写明“研究保留：账户无该板块交易权限，不形成买入动作”。
  - 被排除的代码写入 `research.reason`，不会静默消失。
- 契约：快照校验时，若机会提示或换仓比较点名了受限板块，按契约违反拒绝。
- 字段由所有者写入自己的政策文件，任何命令都不创建或修改该文件（同 [operations](../operations.md) 政策节）。开通权限后删掉该字段即可恢复。

## 2 不变

止损档位、L3、P0–P3、W1、风险预算数值、monitor-v1 `schema_version` 均不变。已有持仓不受影响（当前无科创板持仓）。

## 3 测试

用真实数据，并配互变：
- 688578 冒烟卡片：受限后研究行与立场保留、无机会提示；限制 `BSE` 时不受影响；契约拒绝受限板块的提示。
- 11-02 生产机会成本卡片：创业板 300750 不受 `STAR` 限制；把它改标为科创板代码后被排除，忽略限制生成的快照被契约拒绝。
- `position-size`：拒绝科创板，主板与创业板的结果不变。
- 风险政策：在有/无账户范围时都生效，非法取值 fail-closed。
- 快照组装：把政策字段传入研究摘要。
