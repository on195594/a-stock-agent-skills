## 6. Safety Boundary Assessment

1. **SQLite Online Backup API 保持严谨**：[Spec Section 10.2](file:///home/lin/a-stock-agent-skills/docs/specs/2026-08-08-portable-a-stock-agent-skills-spec.md#L398-L403) 明确使用 Python `sqlite3.Connection.backup` / Online Backup API 生成一致快照；WAL checkpoint 仅作为带锁维护步骤，不作为替代 Backup API 的充分条件，符合 fail-closed 数据安全标准。
2. **状态目录与配置文件权限门禁**：[Spec Section 7.1](file:///home/lin/a-stock-agent-skills/docs/specs/2026-08-08-portable-a-stock-agent-skills-spec.md#L288) 规定 `paths.py` 创建状态目录时权限强制为 `0700`，配置文件必须为当前用户所有且权限不超过 `0600`，彻底阻断多用户环境下的隐患。
3. **通知与 Cron 强隔离**：[Spec Section 7.3](file:///home/lin/a-stock-agent-skills/docs/specs/2026-08-08-portable-a-stock-agent-skills-spec.md#L324) 规定 `A_STOCK_NOTIFY_MODE` 默认 `disabled`，Fixture/Shadow 模式下强制屏蔽 Telegram 发送。生产 DB/Cron 切换定于 M7，且必须经由人工独立审批（Spec Section 19），不影响 M1-M6 的 Fixture-first 安全实施。
